خمین لایف - نسخه وب‌اپ قابل نصب

محتویات این پوشه را بدون تغییر ساختار روی یک هاست HTTPS آپلود کن. فایل index.html باید در ریشه سایت باشد.
بعد از باز کردن آدرس سایت با Chrome اندروید، از منوی مرورگر گزینه Install app / افزودن به صفحه اصلی را بزن.

برای نصب PWA، سایت باید HTTPS داشته باشد؛ باز کردن مستقیم فایل HTML از حافظه گوشی کافی نیست.
ذخیره بازی در حافظه همان مرورگر و همان آدرس سایت انجام می‌شود و با پاک کردن داده‌های مرورگر ممکن است از بین برود.

بازی برای اولین بار به اینترنت نیاز دارد تا کتابخانه سه‌بعدی بارگیری شود. Service Worker پس از بارگیری موفق، فایل اصلی کتابخانه را برای دفعات بعد cache می‌کند؛ تضمین آفلاین بودن همه منابع بیرونی وجود ندارد.
